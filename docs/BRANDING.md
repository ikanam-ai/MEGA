# MEGA Branding

This document keeps the public-facing repository presentation consistent.

## Logo

The logo uses a measurement compass to represent the shared MEGA idea:
LLM passports should be reproducible measurements, not one-off impressions.

- `assets/mega-logo.svg` is the README header lockup.
- `assets/mega-mark.svg` is the compact square mark.

## Track Colors

| Track | Color | Meaning |
| --- | --- | --- |
| VIBE | Cyan | affective profile and Valence-Arousal measurement |
| STONIC | Amber | value profile and Schwartz-oriented normative structure |
| PROOF | Green | factual coverage and reliable extraction |

Purple is used only as a shared umbrella accent.

## Naming

Use the following public names unless the team agrees otherwise:

- MEGA - Make Evaluation Great Again
- VIBE - Valence-Informed Benchmark of Emotion
- STONIC - Schwartz-Theory-Oriented Normative Integrity Check
- PROOF - Profiling Reliability Of Object-level Facts

## Release Language

For tracks that are not yet accepted, keep this exact note in the track README:

```text
Note: The code and benchmark would be released here after review.
```
