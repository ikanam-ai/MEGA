# Measurement Contract Template

Use this template when adding or revising a MEGA research track.

## Object of Study

Define the model behavior or model-associated artifact being measured.

## Construct

Define the target construct independently from the operational measurement.

## Operationalization

Describe the item bank, prompting protocol, response schema, scoring method,
and aggregation procedure.

## Neutral Core

Define the fixed baseline measurement protocol.

## Drift Factors

List all factors that may be varied after the neutral core is fixed, such as:

- language
- role
- prompt template
- response format
- inference parameters
- time or model version

## Reliability Checks

Define reruns, prompt variants, temporal checks, scorer agreement, and any
other stability criteria.

## Release Gate

State whether the item bank, code, benchmark, and results are public,
withheld during review, or internal only.
