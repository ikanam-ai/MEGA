# Shared Documentation

This directory is reserved for umbrella-level documentation that applies to
all MEGA tracks.

Current shared docs:

- `MEASUREMENT_CONTRACT_TEMPLATE.md` - common structure for track protocols
- `BRANDING.md` - logo, colors, names, and release language

Track-specific protocol details will live inside each track after review:

- `VIBE/docs/`
- `STONIC/docs/`
- `PROOF/docs/`
