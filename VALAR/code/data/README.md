# Evaluation data

- `schwartz10_ru_1000.jsonl`: balanced Russian gold bank used for the main
  Schwartz-10 recognition experiment.
- `schwartz10_summary.json`: label and validation summary for that bank.
- `l0_h0_100.jsonl`: 100-item ancillary recognition bank.
- `l0_h0_manifest.json`: provenance and task-family counts for the ancillary bank.

Full construction intermediates, predictions, and human-validation artifacts
are archived on [OSF](https://osf.io/u56kq/overview?view_only=1c3bc242d37247de83e92113d7837be3).
