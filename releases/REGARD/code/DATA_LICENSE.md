# Data licensing

The MIT License in this repository applies to source code only.

The target bank incorporates identifiers and metadata derived from sources
such as Wikidata and UNESCO records, while the response archive contains
outputs from multiple language-model providers. Those artifacts may carry
source-specific attribution requirements or provider terms. The OSF record is
the authoritative distribution point for data files and their provenance.

No operational annotator credential file is part of the research release.
